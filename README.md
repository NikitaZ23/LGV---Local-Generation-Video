# LGV

Local Generation Video. Локальный MVP для поиска и экспорта интересных фрагментов из видео.

## Требования

Установка npm-пакетов не нужна. Приложение использует встроенные модули Node.js, локальный Python-пакет PySceneDetect и инструменты из `E:\AI`:

- Python: `E:\AI\Projects\LGV\.venv\Scripts\python.exe`, если окружение создано; иначе `C:\Users\User\AppData\Local\Programs\Python\Python310\python.exe`
- PySceneDetect: `E:\AI\Projects\LGV\.deps\python\scenedetect`
- FFmpeg: `E:\AI\Tools\ffmpeg-release-essentials\ffmpeg-9.0.1-essentials_build\bin\ffmpeg.exe`
- FFprobe: `E:\AI\Tools\ffmpeg-release-essentials\ffmpeg-9.0.1-essentials_build\bin\ffprobe.exe`
- Whisper CUDA: `E:\AI\Tools\whisper-cublas-12.4.0-bin-x64\Release\whisper-cli.exe`
- модель Whisper: `E:\AI\Models\ggml-large-v3-turbo.bin`
- модель OpenCLIP: `E:\AI\Models\OpenCLIP\ViT-B-32-laion2B-s34B-b79K\open_clip_pytorch_model.bin`

Проект не читает и не изменяет `LVT-Portable`.

## Запуск

Двойной клик по файлу:

```text
LGV.bat
```

Батник сам перейдёт в папку проекта, проверит Node.js, не запустит второй сервер, если LGV уже работает, и откроет обычный браузер Windows на `http://127.0.0.1:5177`.

Если нужно запустить без открытия браузера:

```cmd
LGV.bat --no-browser
```

Ручной запуск:

```powershell
cd "E:\AI\Projects\LGV"
npm run dev
```

Открыть:

```text
http://127.0.0.1:5177
```

## Установка Python-зависимостей

Для нового клона создайте отдельное окружение LGV и установите зависимости:

```powershell
cd "E:\AI\Projects\LGV"
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Веса OpenCLIP и Whisper не хранятся в репозитории. Положите их в `E:\AI\Models` или задайте свои пути через переменные окружения `LGV_OPENCLIP_MODEL`, `LGV_WHISPER_MODEL`, `LGV_FFMPEG`, `LGV_FFPROBE`, `LGV_WHISPER`.

## Использование

Нажмите `Выбрать`, укажите видео в окне выбора Windows, задайте количество лучших фрагментов и режим, затем запустите анализ. Путь можно вставить вручную, если так быстрее. Готовые фрагменты сохраняются сюда:

```text
data\exports\<job-id>\
```

Кнопка `Открыть MP4` запускает готовый файл через Windows из папки экспорта. Кнопка `Папка` открывает проводник с выбранным файлом.

Кнопки `Открыть фильм` и `Папка фильма` работают с исходным видеофайлом: первая запускает его через Windows, вторая открывает проводник с выбранным исходником.

Если включён чекбокс `Проанализировать весь фильм`, LGV строит карту всего фильма по сценам PySceneDetect, не использует поле `Лучших`, показывает все куски карты и при включённом автоэкспорте вырезает ролики по всей карте.

Поле `Макс., мин` задаёт максимум одного MP4 для формата YouTube Shorts. LGV не подрезает длинный участок в один ролик, а заранее нарезает его на несколько MP4 до 1 минуты каждый. Сервер режет с небольшим техническим запасом, чтобы готовый файл не вылезал за 60 секунд из-за кодека или контейнера.

Если чекбокс выключен, LGV делит видео на последовательные короткие куски, стараясь закрывать границы на сценах PySceneDetect, и выбирает количество лучших фрагментов по полю `Лучших`.

Поле `Запас, сек` добавляет указанное количество секунд до начала и после конца каждого ролика. По умолчанию это 2 секунды; запас входит в лимит 1 минуты, а если клип находится в самом начале или конце фильма, граница аккуратно обрезается по реальной длительности видео.

Каждый кусок получает свой тип интереса, а затем LGV выбирает лучшие фрагменты так, чтобы они не были все одного типа.

Карта фильма использует такие признаки:

- смены сцен, найденные PySceneDetect;
- адаптивный детектор PySceneDetect под конкретное видео;
- пороговый детектор PySceneDetect для затемнений и переходов яркости;
- фильтр слишком близких срабатываний, чтобы быстрый монтаж не давал шум;
- визуальный смысл кадров через OpenCLIP, если включён переключатель `OpenCLIP`;
- громкость и динамика звука;
- плотность распознанной речи и эмоциональные слова, если включён Whisper.

Типы интереса: `Экшен`, `Диалог`, `Эмоции`, `Юмор`, `Визуальная динамика`, `Звук/напряжение`, `Смешанный интерес`, `Спокойный участок`.

В интерфейсе есть настройка `Качество сцен`:

- `Точнее` - основной режим, использует адаптивный детектор и детектор затемнений PySceneDetect;
- `Быстрее` - использует только основной детектор PySceneDetect и подходит для чернового анализа длинных фильмов.

FFmpeg всё ещё используется для извлечения аудио, анализа громкости и экспорта MP4, но поиск сцен теперь выполняет PySceneDetect.

OpenCLIP является дополнительным модулем. Если в окружении LGV не установлены `torch`, `open_clip_torch` и `Pillow`, LGV напишет в лог, что нейроанализ OpenCLIP пропущен, и продолжит обычный анализ по PySceneDetect, звуку и Whisper.
